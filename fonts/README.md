The Barlow and Barlow Condensed font files are self-hosted so the showcase does not request fonts from third-party services.

Original files: [Barlow](https://github.com/google/fonts/tree/main/ofl/barlow) and [Barlow Condensed](https://github.com/google/fonts/tree/main/ofl/barlowcondensed), distributed by Google Fonts.

The font files are unmodified and distributed under the included SIL Open Font License files, `barlow-OFL.txt` and `barlowcondensed-OFL.txt`.
